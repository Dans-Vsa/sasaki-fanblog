Strip adegan memakai 5 still resmi anime (scene-1..5.webp, sumber di assets-manifest.json).
Untuk menggantinya dengan potongan panel manga pendek: taruh WebP di sini (lebar maks 900px), ubah `src` di `PANELS` pada `js/data.js`,
dan catat sumbernya di `assets/assets-manifest.json`. Hanya kutipan pendek untuk ulasan, satu panel per slot.
